API Emission by Units v4.2.x

Welcome to the public documentation for the TravelCash Cashback API. This API enables integrations with the TravelCash cashback ecosystem, providing endpoints for environment validation, auxiliary setup data retrieval, and asynchronous communication with the backend.

Authentication

All endpoints require authentication via the x-client-key header.

x-client-key: <YOUR_CLIENT_KEY>

Important note about extraData

For the POST /api/Public/queue endpoint, the properties userlanguage and salecurrency must be sent inside the extraData JSON object.

Both values must be informed using the GUIDs previously returned by the GET /api/Public/getLanguages and GET /api/Public/getCurrencies endpoints.

If userlanguage and/or salecurrency are not present in extraData, or if they are sent with invalid/unrecognized GUIDs, the API will assume the default values configured in the target unit setup.

{
  "extraData": {
    "userlanguage": "11111111-1111-1111-1111-111111111111",
    "salecurrency": "22222222-2222-2222-2222-222222222222"
  }
}

GET /api/Public/environment

Returns information about the current environment and API status.

Request example

curl -X GET "https://travelcashcustomurl.azurewebsites.net/api/PublicEmission/environment" \
  -H "x-client-key: <YOUR_CLIENT_KEY>"

Response example

{
  "environment": "Development"
}

GET /api/Public/getLanguages

Returns the list of languages available in the system.

Each item contains the language GUID, code, and name. The returned GUID must be used in extraData.userlanguage when calling POST /api/Public/queue.

Request example

curl -X GET "https://travelcashcustomurl.azurewebsites.net/api/PublicEmission/getLanguages" \
  -H "x-client-key: <YOUR_CLIENT_KEY>"

Response example

[
  {
    "guid": "11111111-1111-1111-1111-111111111111",
    "code": "pt-BR",
    "name": "Portuguese (Brazil)"
  },
  {
    "guid": "33333333-3333-3333-3333-333333333333",
    "code": "en-US",
    "name": "English (United States)"
  }
]

GET /api/Public/getCurrencies

Returns the list of currencies available in the system.

Each item contains the currency GUID, code, and name. The returned GUID must be used in extraData.salecurrency when calling POST /api/Public/queue.

POST /api/Public/pingpong

Test communication with the environment and authentication verification.

Request Body (LoginApp)

FieldTypeDescription
loginstringUsername
passwordstringPassword
timeoutInMinutesnumberSession timeout
geolocationstringLocation information
devInfostringDevice information

Request example

curl -X POST "https://travelcashcustomurl.azurewebsites.net/api/PublicEmission/pingpong" \
  -H "Content-Type: application/json" \
  -H "x-client-key: <YOUR_CLIENT_KEY>" \
  -d '{
    "login": "teste",
    "password": "1234",
    "timeoutInMinutes": 15,
    "geolocation": "São Paulo, BR",
    "devInfo": "Windows 11"
  }'

Response example

{
  "accountDetails": "teste",
  "token": "Development",
  "result": true,
  "message": "Pong! 10/06/2025"
}

POST /api/Public/queue

Inserts an item into the asynchronous processing queue (e.g., cashback generation).

Request Body (ProcQueueInsertRequest)

FieldTypeDescription
valuenumberOperation amount
identificatorstringUnique identifier
userNamestringUser's name
userMailstringUser's email
userPhonestringUser's phone number
checkoutTimedate-timeCheckout date and time
qualifierobjectAdditional qualifiers
extraDataobjectExtra information, including optional userlanguage and salecurrency GUIDs

Request example

curl -X POST "https://travelcashcustomurl.azurewebsites.net/api/PublicEmission/queue" \
  -H "Content-Type: application/json" \
  -H "x-client-key: <YOUR_CLIENT_KEY>" \
  -d '{
    "value": 199.90,
    "identificator": "TRX-20251006-001",
    "userName": "Maria Silva",
    "userMail": "maria@example.com",
    "userPhone": "+5511999998888",
    "checkoutTime": "2025-10-06T14:30:00",
    "qualifier": {"channel": "web"},
    "extraData": {
      "origin": "checkout",
      "userlanguage": "11111111-1111-1111-1111-111111111111",
      "salecurrency": "22222222-2222-2222-2222-222222222222"
    }
  }'

Response example

{
  "result": true,
  "message": "Request queued successfully.",
  "idProcQueue": "123e4567-e89b-12d3-a456-426614174000"
}

TravelCash Cashback API v4.2

Bem-vindo à documentação pública da TravelCash Cashback API. Esta API permite integrações com o ecossistema de cashback da TravelCash, oferecendo endpoints para validação de ambiente, consulta de dados auxiliares de configuração e comunicação assíncrona com o backend.

Autenticação

Todos os endpoints exigem autenticação via header x-client-key.

x-client-key: <SEU_CLIENT_KEY>

Observação importante sobre extraData

Para o endpoint POST /api/Public/queue, as propriedades userlanguage e salecurrency devem ser enviadas dentro do objeto JSON extraData.

Ambos os valores devem ser informados utilizando os GUIDs retornados anteriormente pelos endpoints GET /api/Public/getLanguages e GET /api/Public/getCurrencies.

Se userlanguage e/ou salecurrency não estiverem presentes em extraData, ou forem enviados com GUIDs inválidos/não reconhecidos, a API assumirá os valores padrão configurados no setup da unit de destino.

{
  "extraData": {
    "userlanguage": "11111111-1111-1111-1111-111111111111",
    "salecurrency": "22222222-2222-2222-2222-222222222222"
  }
}

Insere um item na fila de processamento assíncrono (ex: geração de cashback).

CampoTipoDescrição

identificatorstringIdentificador único
userNamestringNome do usuário
userMailstringEmail do usuário
userPhonestringTelefone do usuário

curl -X POST "https://travelcashcustomurl.azurewebsites.net/api/PublicEmission/queue" \

  -d '{

    "identificator": "TRX-20251006-001",
    "userName": "Maria Silva",
    "userMail": "maria@exemplo.com",
    "userPhone": "+5511999998888",

    "qualifier": {"canal": "web"},
    "extraData": {
      "origem": "checkout",

{
  "result": true,
